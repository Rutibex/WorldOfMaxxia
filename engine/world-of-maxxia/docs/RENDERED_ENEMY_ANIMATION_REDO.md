# Illustrated Enemy Animation Replacement (0.29.2)

The Phase 27–29 post–Dust Imp monster art had been generated by Pillow primitive drawing code. It failed to match the illustrated style of the Dust Imp and Xeen-like reference animations. This correction replaces the eight ordinary sheets and Bell-Heart special sheet with rasterized painted character poses. The illustration master, cropped atlases and metadata are bundled under `art-source/enemy-raster-redo/`.

| Species | Illustration themes |
| --- | --- |
| Stone Mite | articulated rock carapace, raised armored forelimbs, collapsing body |
| Gallery Watcher | giant animated eye, writhing tentacles, blue discharge, injured fall |
| Cistern Rat | bristling fur, lunging bite, recoiling head, collapsing body |
| Sludge Leech | undulating muck, massive gaping maw, dripping sludge, collapse |
| Pipe Goblin | expressive green goblin with a pipe weapon and full-body swings |
| Bell Wraith | ghost robes, bright cold light, forward surge, dissolution |
| Valve Sentinel | heavy clockwork limbs, hammering / sideways strikes, fall |
| Bell-Heart Custodian | armored brass core, blue discharge, pronounced impact and collapse |

**Source vs sprite format:** `rendered-enemies-master.png` (painted character animation reference, with tiled magenta background and labels) is the sole source used for cropping. `pack-rendered-enemies.py` uses no polygon/ellipse/line drawing; it extracts artist poses, removes the chroma background, and packs 16 transparent frames per species in four 128px columns. Six idle frames are sequenced 0,1,2,3,2,1; last death holds may be faded. This is a materially illustrated upgrade, but not sixteen individually commissioned poses per monster.

**Playback:** `src/client/combat-art.ts` retains actual combat event selection and frame counts, then uses appearance-only transforms (lunge/recoil/sink/charge) to add energy; reduced-motion freezes this transform and existing frame playback. It does not modify enemy HP, encounter RNG, turn timing or saves.

**Audit:** Old primitive generators are preserved in `art-source/legacy-procedural-enemies/` for provenance but are not executable build tasks. The Dust Imp and other prior artwork are unchanged. A transparent PNG is the only output of the new active enemy packer, not vector objects.
