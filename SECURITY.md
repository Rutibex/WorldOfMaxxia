# Security policy

This is a preview software project with no public security support SLA. If you discover a vulnerability involving exported/imported saves, pack parsing, local file handling, or the companion server, please use the repository's **private vulnerability reporting** feature if enabled. Otherwise open a GitHub issue without including exploit payloads, secrets or personal information, and request a private contact method.

Do not include passwords, API keys, or private data in issues. The supplied local HTTP server should be used on loopback (`127.0.0.1`) for personal play and is **not** intended as a production-facing public hosting service. Use GitHub Pages or another appropriately configured static host for the public browser demo.
