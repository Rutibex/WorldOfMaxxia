# MP23 validation protocol

Gates: strict local TypeScript check; MP23 focused and complete game regression; generated contract sync; two composed proof catalogues; successful offline browser build; byte-for-byte localhost HTTP verification including 404; source/built-browser scenario parity with saved party state, item charge, trap state and receiving-pack portable character. A missing optional npm AJV dependency is a separately reported unverified gate, not a pass.

The release checker requires validation logs and accurate ledger/build info. The browser and source ZIPs must both pass archive CRC. Interactive visual playthrough and Windows editor compilation are independent future gates.
