# Changelog

This public changelog records meaningful feature milestones rather than internal phase handoff logs.

## MP27 · 8 November 2026 · engine 0.72.0 / workspace 0.27.0-mp27

- Added authored perception and illusion features: false walls, false openings and illusory scenery, without changing authoritative collision or game-state rules.
- Added sequence, alignment and combination puzzle controls with clues, failure responses, reveal events and persistent state.
- Extended the module authoring toolkit and sample **Counterfeit Gallery** pack to exercise the new mechanics.
- Retained earlier terrain and mutable route systems from MP26, scene/sprite contracts from MP24–MP25, and portable campaign packs and prior gameplay systems.
- Prepared source repository, distributable browser archive, project documentation, CI and a GitHub Pages landing/play site.

This is a *preview* release. Automated engine logic tests exist; full manual GPU/browser/touch and Windows-editor acceptance remains outstanding.
